Component
A trait an entity has. Plain data.
One container per component type, indexed by entity ID. Holes where the entity doesn't have it.
What an entity is = the components it has. No Health → can't be damaged.
Change them at runtime: remove Collider → invincible. Add Input → a Bydos you control.
If it has a method with game logic in it, it's not a component.
Never keep a pointer or reference to a component: the vector resizes and relocates. Keep the entity ID and look it up again.
