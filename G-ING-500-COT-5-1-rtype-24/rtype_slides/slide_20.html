Scene Loader
From a .yaml file to a live registry.
Two passes: create everything, then link parents. Order in the file doesn't matter.
Bad file = clear error, never a crash: level1.yaml:14 unknown prefab "bydoss".
Unload = destroy the scene's entities, release its assets.
Online, only the room loads the file. It then streams the spawns to its clients — that's their loading screen.
