Epitech Afrique — Track #3 · Weapons
The Force
One weapon, a whole state machine.
Attached front: shoots forward, blocks enemy shots.
Attached back: shoots backwards.
Detached: flies off, fights alone. Recall brings it home.
Charge: hold fire, release a super-charged shot.
It's an entity with a ForceState component. One system runs the transitions.
Server decides. "Detach" is an input like any other: the room applies it, the clients show it.
