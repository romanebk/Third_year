Levels
A level is a timeline of spawns, read from a file.
scroll 0 px · the camera is the frame—
# levels/level_1.yaml
name: "Bydo Outpost" music: stage1.ogg scroll: 60 # px/s
background: [stars.png, nebula.png] terrain: outpost.map
waves:
- { at: 400, spawn: bydo, count: 4, pattern: straight }
- { at: 1000, spawn: bug, count: 5, pattern: sine }
- { at: 1600, spawn: crab, count: 2, on: ground }
- { at: 2200, spawn: patapata, count: 3, pattern: chaser }
- { at: 2600, checkpoint: true }
boss: { at: 3200, prefab: dobkeratops.yaml, scroll: stop }
Spawns keyed on scroll distance, not on wall-clock time.
The room reads the file and runs it. Clients only get what to draw.
Obstacles are content too: terrain, walls, closing corridors.
New level = new file. No recompile, no new class.
Give each level a twist. Level 3: a giant vessel for the whole stage. Level 4: monsters leave solid trails. A theme, a rule, a surprise.
