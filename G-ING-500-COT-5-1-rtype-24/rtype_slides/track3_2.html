Monsters
A monster is a pattern + a weapon + a sprite.
# prefabs/bug.yaml — a designer writes this, not C++
Sprite: { sheet: bug.png, frames: 8 }
Health: { hp: 1 }
Movement: { pattern: sine, speed: 120, amplitude: 60 }
Weapon: { shot: aimed, every: 2.0 }
Drop: { powerup: 10% }
One movement system reads pattern and moves everything that has it.
New monster = new file, not a new class. Mix patterns and weapons: few pieces, many monsters.
The subject's examples: the snake of level 2, ground turrets.
