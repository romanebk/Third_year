Epitech Afrique — Engine
From exec to exit
What the engine does between ./r-type_client and return 0.
exec 1
  • run the project's binary
  • it lives in the project dir
  • assets & resources right next to it
›
boot 2
  • config, logger first
  • core modules up
  • plugin loader → .so / factory
›
load 3
  • read project.json
  • assets → assets manager
  • first scene → registry filled
›
loop 4 · until quit
  • poll input & network → events
  • fixed-step update: run the systems
  • render, then wait for next frame
poll›update›render↺
›
shutdown 5
  • unload scene
  • plugins & modules in reverse order
  • flush logs → return 0
